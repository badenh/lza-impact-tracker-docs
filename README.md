# lza-impact-tracker-docs

Static site presenting the LZA Impact Tracker analysis. Loads the JSON
artifacts generated by
[lza-impact-tracker-code](https://github.com/badenh/lza-impact-tracker-code)
and drives an interactive view of every published LZA Compliance Workbook
version.

## Structure

```
index.html          shell + sections
css/site.css        styling
js/app.js           data loading + Chart.js views
data/               JSON artifacts (copied from lza-impact-tracker-code/out/)
```

## Local preview

No build step. Serve the directory:

```bash
python3 -m http.server 8000
open http://127.0.0.1:8000/
```

## Refreshing data

The JSON in `data/` is generated by the code repo. From the sibling
`lza-impact-tracker-code`:

```bash
make publish
```

That target regenerates `out/*.json` and copies it into
`../lza-impact-tracker-docs/data/`.

## Views

1. Versions at a glance — totals per workbook version.
2. Framework coverage in one version — bar chart + table.
3. Drill into one framework — related-control breakdown, cross-version presence.
4. Drill into one LZA ID — presence per version + framework × version heat map + full mapping table.
5. Drill into one framework control — LZA IDs mapped, cross-version presence.
6. Hot lists — top LZA IDs and top related controls by raw count.
